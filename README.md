# Smart Dormitory System

An IoT-based smart dormitory prototype developed as a university course project.

## Features

- Occupancy detection
- Temperature monitoring
- Sound detection
- MQTT communication
- Node-RED dashboard

## Hardware

- ESP32
- Arduino UNO
- Thermistor
- Microphone Sensor
- IR Sensor

## Software

- Arduino IDE
- Node-RED
- MQTT
